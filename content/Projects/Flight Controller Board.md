# Core Features

- [ ] Voltage and Current Monitor {INA219}
- [ ] IMU {LSM6DSLTR}
- [ ] ESC Driver {}
- [ ] USB-C Connector {USB-C HS}
- [ ] GNSS Module {Ublox M3}
- [ ] Buzzer (Sound detection) {SMD passive buzzer}
- [ ] Receiver 
- [ ] ESP32 C3 (for WIFI and Bluetooth)
- [ ] Temperature Sensor {}
- [ ] Flash or EEPROM 
- [ ] Pressure Sensor
- [ ] Backup Batt (if the main batt are remove or it's voltage is down, turn off the most power things and send a message throw WIFI)
- [ ] 8 PWM channels for servos & ESC
- [ ] SD Card
- [ ] Magnetic Sensor
- [ ] External connection connectors (if u can)
